# Помню состав

Тренажёр для заучивания составов хлеба и выпечки кафе «Остоженка».

- **Обучение** — курс из 7 уроков: теория основы → тест, теория позиции → тест, «что есть что» по фото, итоговый тест. План на день и экзамен 31 октября.
- **Карточки** и **Квиз** — «Собери состав», «Найди лишнее», «Угадай по составу».
- **Прогресс** — уровни, XP, слабые места.

## Хостинг

Сайт — один статический файл `index.html` (фото встроены внутрь, ~3 МБ). Сервер и сборка на хостинге не нужны: укажите корень репозитория как папку публикации (GitHub Pages, Netlify, Vercel, любой статический хостинг).

Прогресс на хостинге хранится в браузере посетителя (localStorage). В версии на claude.ai он дополнительно сохраняется в аккаунте Claude.

## Как поменять

Правки вносятся в исходники, затем сборка:

```bash
node build.js
```

| Файл | Что в нём |
|---|---|
| `game.src.html` | вёрстка, карточки и квизы |
| `course.engine.js` | раздел «Обучение»: уроки, план дня, сохранение |
| `data/course.src.js` | программа курса: основы, модули, уроки |
| `data/dishes.json` | составы из памятки |
| `data/photos.json` | фото позиций |
| `data/glossary.json` | словарь терминов |
| `index.html` | готовая страница для хостинга |
| `claude-artifact.html` | та же страница для публикации в Claude |
